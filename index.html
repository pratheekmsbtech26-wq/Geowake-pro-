Android Background Location Guide

Why Web Apps Need Foreground Active Tabs:

Mobile web browsers restrict background GPS when the screen turns off. To build a 100% reliable commercial app, you build a native Android app using Google Play Services Geofencing API + Foreground Service.

1. Required Android Permissions (AndroidManifest.xml)

<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_BACKGROUND_LOCATION" />
<uses-permission android:name="android.permission.FOREGROUND_SERVICE" />
<uses-permission android:name="android.permission.USE_FULL_SCREEN_INTENT" />

2. Kotlin Geofence Registration Snippet

val geofence = Geofence.Builder()
    .setRequestId(alarmId)
    .setCircularRegion(lat, lng, radiusMeters)
    .setTransitionTypes(Geofence.GEOFENCE_TRANSITION_ENTER)
    .setExpirationDuration(Geofence.NEVER_EXPIRE)
    .build()

val request = GeofencingRequest.Builder()
    .setInitialTrigger(GeofencingRequest.INITIAL_TRIGGER_ENTER)
    .addGeofence(geofence)
    .build()

geofencingClient.addGeofences(request, geofencePendingIntent)
